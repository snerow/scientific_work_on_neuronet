СОЗДАНИЕ ПРИЛОЖЕНИЯ С ИСПОЛЬЗОВАНИЕМ НЕЙРОСЕТЕЙ

В статье приведено создание приложения с использованием нейросетей. В качестве примера приложения была выбрана игра Тетрис. Изучаемые нейросети: DeepSeek и ChatGPT. Работа была выполнена с целью показать тонкости создания приложений с помощью ИИ и узнать, может ли обычный пользователь, не имеющий знаний в области IT, с использованием нейросетей создать своё приложение (в нашем случае, игру).
